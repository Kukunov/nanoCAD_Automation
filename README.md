# GOST 21.208 nanoCAD Automation

Надстройка для nanoCAD 25.0, автоматизирующая проектирование схем автоматизации по ГОСТ 21.208-2013

## Возможности

- Вставка стандартных графических обозначений:
  - `ПНЩ` / `PNSH` — прибор на щите 
  - `ПВЩ` / `PVSH` — прибор вне щита 
- Автоматическая генерация позиционных обозначений
- Управление контурами автоматизации
- Цветовое кодирование контуров
- Валидация ввода ТИП и ПОЗ
- Сохранение состояния в XData чертежа
- Отображение и экспорт статистики чертежа в CSV и TXT

## Команды

| Команда | Описание |
|---------|----------|
| `ПНЩ` / `PNSH` | Вставить прибор на щите |
| `ПВЩ` / `PVSH` | Вставить прибор вне щита |
| `ГОСТВСТАВКА` / `GOSTINSERTION` | Вставка с выбором типа |
| `ИНФОКОН` / `INFOLOOP` | Информация о контурах |
| `УСТКОН` / `SETLOOP` | Сменить контур |
| `СБРОСКОН` / `RESETLOOP` | Сбросить счётчик |
| `ЦВЕТКОНТУРЫ` / `COLORCONTOURS` | Цветовое кодирование |
| `СБРОСЦВЕТ` / `CLEARCOLORS` | Сброс цветов |
| `ГОСТОКНО` / `GOSTWINDOW` | Панель управления |
| `ГОСТПОМОЩЬ` / `GOSTHELP` | Справка |

## Требования

- Windows 10/11 (x64)
- nanoCAD 25.0
- .NET 6.0 Runtime

## Установка

1. Скачайте `GOST_Automation_Setup.exe` из [раздела Releases](https://github.com/Kukunov/nanoCAD_Automation/releases)
2. Убедитесь что nanoCAD закрыт
2. Запустите установщик от имени администратора
3. Откройте nanoCAD 25.0
4. В меню появится пункт «ГОСТ Автоматизация» (классический интерфейс)

## Удаление

1. Перейдите в каталог, указанный в момент установки  
   (по умолчанию - **C:\Program Files\Nanosoft\nanoCAD x64 25.0\GOST_Automation**)
2. Убедитесь что nanoCAD закрыт
3. Запустите unins000.exe
