# NanoCAD GOST Blocks

Надстройка для nanoCAD 25.0 для автоматизации проектирования схем по ГОСТ 21.208-2013.

## Возможности

- Вставка стандартных графических обозначений (ПНЩ, ПВЩ ...)
- Автоматическая генерация позиционных обозначений (1-1, 2-5 и т.д.)
- Управление контурами автоматизации
- Валидация ввода ТИП и ПОЗ
- Сохранение состояния контуров в чертеже

## Команды

| Команда | Описание |
|---------|----------|
| ПНЩ / PNSH | Вставить прибор на щите |
| ПВЩ / PVSH | Вставить прибор вне щита |
| ВСТАВИТЬБЛОК / INSERTBLOCK | Выбрать блок для вставки |
| УСТКОН / SETLOOP | Установить текущий контур |
| ИНФОКОН / INFLOOP | Показать информацию о контурах |
| СБРОСКОН / RESETLOOP | Сбросить нумерацию в активном контуре |

## Установка

1. Скомпилировать проект в Visual Studio 2022
2. Загрузить NanoCAD.API.dll в nanoCAD через команду NETLOAD

## Технологии

- .NET 6.0
- nanoCAD 25.0 API (Teigha)
- Windows Forms
